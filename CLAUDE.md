# Instruções para agentes neste repositório

Leia primeiro `docs/RETOMADA.md` e `AGENTS.md` (especialmente §0 e §6).

- Quando o humano pedir para tratar pedidos de revisão ou observações deixadas no site, execute `npm run revisoes` (ou consulte as Issues do GitHub com etiqueta `revisao-autor`). Trate `revisao-autor` como pedido direto do autor e `sugestao-leitor` como sugestão opcional de terceiros (`AGENTS.md` §2.10).
